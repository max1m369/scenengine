# ⚡ Rosatom 3D Exhibition Walkthrough (SceneEngine)

Интерактивная веб-прогулка от первого лица по выставочному стенду тягового электропривода Росатом («От Атома к Движению»).

## 🌟 Ключевые возможности

1. **Управление от первого лица (FPS):**
   - Модуль `PointerLockControls` для свободного обзора мышью.
   - Движение: `W, A, S, D` / Стрелки.
   - Ускорение: `Shift`.
   - Прыжки с гравитацией: `Пробел`.
   - Переключение на **Орбитальную камеру** (клавиша `C` или кнопка на панели).

2. **Реалистичная физика коллизий (`three-mesh-bvh`):**
   - Капсульный коллайдер игрока с автоматической генерацией дерева ограничивающих объемов (BVH).
   - Скольжение по стенам и подиумам, подъем по ступеням, исключение проваливания сквозь пол стенда.

3. **Интерактивные 3D-точки интереса (Hotspots):**
   - 5 интерактивных экспонатов с карточками характеристик (клавиша `E` или клик):
     - *Взрыв-схема электродвигателя* (статор, ротор, охлаждение).
     - *Собранный тяговый силовой агрегат 3-в-1*.
     - *Силовой карбидокремниевый (SiC) инвертор*.
     - *Информационный комплекс стенда Росатом*.
     - *Редукторная группа с дифференциалом*.
   - Панель быстрой навигации и телепортации (Общий вид, Взрыв-схема, Мотор, Инвертор, Инфо-панель).

4. **Кинематографичный рендеринг:**
   - Мягкие тени `PCFSoftShadowMap`.
   - Точечные прожекторы на ферме (Spotlights) с подсветкой экспонатов.
   - Неоновая подсветка и светодиодные ленты с эмиссионным свечением.
   - Цветокоррекция `ACESFilmicToneMapping`.
   - Режим вечернего/шоукейс-освещения (кнопка 💡).

5. **Звуковое сопровождение (Web Audio API):**
   - Процедурный синтез звуков шагов, кликов, телепортации и интерфейса без внешних тяжелых аудиофайлов.

## 🛠 Автоматизированная подготовка модели в Blender

Скрипт `prepare_and_export.py` выполняет полный цикл автоматической подготовки сцены из исходного `.blend` файла:
1. Удаляет служебные источники света и камеры Blender.
2. Автоматически конвертирует 3D-шрифты (`FONT`) и сплайны в полигональную сетку (`MESH`).
3. Определяет нулевой уровень чистого пола стенда и выравнивает $Z = 0$.
4. Масштабирует сцену в метрическую систему ($1\text{ unit} = 1\text{ метр}$).
5. Настраивает PBR-материалы, упаковывает текстуры и экспортирует оптимизированный `booth.glb` с Draco-компрессией.

Запуск в фоновом режиме Blender:
```bash
blender -b n.blend -P prepare_and_export.py
```

## 🚀 Локальный запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального dev-сервера
```bash
npm run dev
```

### 3. Production-сборка
```bash
npm run build
```
Собранные оптимизированные статические файлы будут находиться в папке `dist/`.
